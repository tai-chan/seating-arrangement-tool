# 座席配置図作成ツール

研修・イベント運営向けの座席配置図を、ドラッグ＆ドロップで素早く作成できるツールです。

**公開URL**: https://tai-chan.github.io/seating-arrangement-tool/

## 主な機能

- 家具の配置: I字机（2:2 / 3:3）・T字机・丸机・スクリーン・講師席・MC・事務局
- ドラッグでの移動、四隅ハンドルでの回転・拡大縮小
- 机を選択して座席数・テーブルクロスの色（赤・青・緑・黄）を変更（座席マーカーが連動して増減）
- 座席へのアルファベット自動採番（A, B, C…, AA, AB…）
- 会場全体テンプレートのワンクリック生成（2スクリーン＋事務局パターン／1スクリーン・グリッド）
- PNG画像として書き出し

## 使い方

上記URLをブラウザで開くだけです。インストール・ビルドは不要です。

## 技術構成

- Vanilla JS（ビルドツールなし）
- [Fabric.js](http://fabricjs.com/) 5.3.0（CDN読込）
- GitHub Pages（`main` ブランチ, `/` root）でホスティング
